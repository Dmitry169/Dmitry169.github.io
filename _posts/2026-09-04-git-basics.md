Git - распределённая система контроля версий. основные команды: 'git add' для индексикации изменений, 'git commit' для фиксации, 'git push'/'git pull' для синхронизации с удалённым репозиторием. в этом проекте Git используется для хранения и публикации сайта на GitHub Pages.
